EVENTPIC V17 — PASSOS NO SUPABASE

1) Abrir SQL Editor no projeto jwdxnjdwidntkushelal e executar supabase-schema.sql.
2) Authentication > Users > Add user: criar o utilizador do Dashboard com o email escolhido e password.
3) No SQL Editor, autorizar esse utilizador (trocar EMAIL_AQUI):

insert into public.staff_users(user_id,email,role)
select id,email,'admin' from auth.users where lower(email)=lower('EMAIL_AQUI')
on conflict (user_id) do update set active=true, role='admin';

4) O Portal dos Noivos (index.html) continua sem login.
5) O Dashboard (dashboard.html) exige email/password e valida a allowlist staff_users.
6) Leads manuais já ficam no Supabase. A função create_public_lead está pronta para a landing page.
7) Publicar a função separadamente no Supabase: supabase functions deploy meta-webhook.
8) Configurar os secrets META_VERIFY_TOKEN e META_APP_SECRET no Supabase. O META_APP_SECRET é usado para validar a assinatura de todos os POST da Meta.
9) Configurar o Page Access Token/permissões na Meta para transformar leadgen_id nos dados completos do lead.
10) Depois de executar o SQL, testar: login do dashboard, abertura de um link /noivos, upload JPG/PNG/WebP até 10 MB e gravação da personalização.

NUNCA colocar sb_secret/service_role em config.js ou HTML.
